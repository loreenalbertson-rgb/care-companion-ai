# 💙 Care Companion AI

Care Companion AI is a caregiver support application designed to help families organize medical information, prepare for appointments, track symptoms, and create clearer questions for healthcare professionals.

Caregiving often involves managing overwhelming amounts of information. This project was created to make that process feel more organized, understandable, and supportive.

## Live Application

A live demonstration link will be added here after deployment.

## Features

### Medical Information Simplifier

Organizes complicated medical notes, diagnosis descriptions, discharge instructions, and test information into a clearer structure.

### Doctor Question Generator

Creates helpful questions caregivers can bring to medical appointments based on symptoms, concerns, and care goals.

### Symptom Journal

Records symptoms and observations, including:

* Date
* Severity
* Timing and duration
* Possible triggers
* Additional caregiver notes

### Medication Organizer

Creates a temporary medication list containing:

* Medication name
* Dose
* Schedule
* Purpose
* Questions or observations

### Appointment Preparation

Turns caregiver observations into a downloadable appointment summary that can be reviewed with the medical care team.

### Caregiver Support

Provides a gentle caregiver check-in and reminders to address basic personal needs during stressful care situations.

## Why I Built This

Families and caregivers are often expected to understand complex medical information while also managing appointments, symptoms, medications, and emotionally difficult decisions.

I created Care Companion AI to explore how thoughtful technology can support caregivers without replacing the essential role of qualified healthcare professionals.

## Privacy Approach

This early version does not use a permanent database.

Information entered into the symptom journal and medication organizer is kept temporarily within the active Streamlit session. Users should still avoid entering identifying or highly sensitive medical information into demonstration applications.

## Medical Disclaimer

Care Companion AI is an educational and organizational project.

It does not:

* Diagnose medical conditions
* Recommend treatments
* Prescribe medications
* Replace a doctor or qualified healthcare professional
* Provide emergency medical services

For severe, sudden, or life-threatening symptoms, call 911 or seek immediate medical care.

## Run Locally

Clone the repository:

```bash
git clone https://github.com/YOUR-USERNAME/care-companion-ai.git
```

Move into the project folder:

```bash
cd care-companion-ai
```

Install the required package:

```bash
pip install -r requirements.txt
```

Start the application:

```bash
streamlit run app.py
```
